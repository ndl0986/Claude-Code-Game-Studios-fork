# Kid Learn Character: content list (A–Z, 0–9)

**Status:** Draft for review (TASK-029, 2026-11-17). Owner: game-art-content.
**Source:** `design/game-brief.md` (Content, first set; Rules the team keeps from day one).
**Art:** this list is style-neutral. 2D or 3D is decision K-01 (see `art-sound-options.md`).

## How to read this list

- **Object** is the pick. **Backups** can replace it without changing anything else.
- **Object sound** is a short sound effect that plays with the picture, or "none". "None" keys
  get a soft generic "pop" sparkle, so every press still makes a sound.
- **Spoken line (EN)** is what the voice says, in this order: the letter name, a short pause, then
  the word. "D… dinosaur!" is the pattern from the brief.
- **VI line (later)** stays empty until Luan decides K-02 (language). Note that a Vietnamese word
  usually won't start with the same letter (D is "khủng long"), so the Vietnamese line may need
  its own design. That's not part of this task.
- The table becomes data later (brief: "key → picture → sound table is data"). The column names
  map to fields: `key`, `object`, `backups`, `picture`, `sfx`, `line_en`, `line_vi`.

## Toddler-safe rules used for every pick

1. **Recognisable at a glance** by a 2–4-year-old: everyday animals, food, toys, vehicles. No
   abstract or rare things.
2. **Nothing scary or violent:** no weapons, fire, skulls, spiders, snakes, sharks, wolves,
   volcanoes or knives. Big animals (dinosaur, lion, whale) are drawn friendly: round shapes,
   smiling, no visible teeth or claws. Their sounds are short and soft, never sudden or loud.
3. **No brand names or known characters:** generic objects only. Nothing should look like a famous
   cartoon (no recognisable mouse, train face, princess or dinosaur from a show).
4. **The word starts with the letter's usual sound.** No silent letters (knife, knee), no odd
   starts (xylophone /z/, giraffe soft g, cereal soft c). Vowels use their short sound (A apple,
   E elephant, I igloo, O octopus, U umbrella), which is the sound children meet first in phonics.
   **The one exception is X.** See the X row and the note under the table.
5. **The word is not the letter name.** "B… bee" or "Y… yew" would teach that the word *is* the
   letter, so those are avoided.
6. **Each object appears once.** A backup on one letter can be a counting object for 0–9, but no
   object is the main pick on two keys.

### Notes on single letters

- **X (choice: fox).** Almost no toddler word starts with X's usual sound /ks/. "Xylophone" starts
  with /z/, and "X-ray" says the letter name and usually shows a skeleton (scary for this age). So
  X uses a word that **ends** in /ks/. **Fox** is picked over **box** because an animal holds a
  toddler's attention better than an empty box. On this one key the picture also shows the
  written "x" glowing, so the link is visible without reading. Backup **ox** ends the same way.
  This is the only key that breaks rule 4, and the exception is deliberate.
- **D (dinosaur) and L (lion).** These are the two "big animal" keys. Both are drawn as babies or
  friendly shapes with closed or smiling mouths. Their sounds are capped short (about 1 s) and
  quieter than the other sounds (see "Sound limits" in `art-sound-options.md`). D keeps the roar
  because the brief names it. L uses a softer rumble so the two don't sound alike.
- **I (igloo).** Short-i words are hard for toddlers. Igloo is the most common picture in alphabet
  books. A Vietnamese toddler may not know it. If playtests show they don't, the backup **insect**
  (a ladybird) is the fallback. "Ice cream" was rejected: it starts with the long "eye" sound,
  which is the letter name (rule 5).
- **B (ball), not bee.** "B… bee" says the same sound twice (rule 5).
- **Q (queen).** Q is the only letter whose usual start is two sounds (/kw/). That is normal for Q
  and is accepted. The queen must be generic, not based on any real person or famous character.
- **W (whale).** The word is spelled "wh", but it starts with /w/. That passes rule 4.
- **T (train).** Draw it without a face, so it can't look like a famous TV train.
- **E (elephant), not egg.** Egg is the backup and is also the counting object for 6.

## Numbers 0–9

The counting picture lays the objects out in a **dice / ten-frame pattern** so a toddler can see
"how many" without counting one by one. Objects pop in **one at a time** while the voice counts.
Each number uses a different, simple, same-size object, so pressing numbers stays interesting.
Counting objects can repeat a letter's backup, but not a letter's main pick (rule 6).

### Notes on numbers

- **Spoken line** follows the brief ("1 → ONE + 'one'"): the number word only. The count-along is
  an option for the game design. It makes 9 last about 4 s, which may be too long when a toddler
  is mashing keys, and the brief says the next press replaces the current one at once. Recommend
  keeping it in the data and letting the GDD decide when it plays.
- **Zero** shows an empty basket rather than "zero apples", because nothing to count is the idea.
- **Strawberry, not apple, for 1.** Apple is A's main pick (rule 6).
- **Plurals are regular** (balloons, ducks, cars…). "Fish" and "sheep" were avoided because their
  plural is the same word.
- **Word on screen.** The numeral is the main shape. The word (ONE) is shown small under it for
  grown-ups; the child isn't expected to read it (brief: "no text the child needs to read").

## Questions for Luan (sent to the leader as text; not in decisions.md)

1. **US or UK English voice?** It changes Z ("zee" or "zed"), some words (ladybug or ladybird),
   and the vowels in "tomato"-type words. Nothing in this list depends on it except the Z letter
   name. Recommended: pick one before recording voice-over.
2. **Letter name or letter sound first?** The brief's pattern is the letter **name** ("D…
   dinosaur"). Many phonics apps say the **sound** ("duh… dinosaur"). This list follows the brief.
   Adding a sound-first mode later would need a second recording per letter.
