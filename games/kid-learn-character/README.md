# Kid Learn Character (working title)

A toddler game for learning letters and numbers: press a key, see a picture, hear its sound.

- Kickoff notes: `production/team/kickoff-notes.md`
- Board: `production/team/board.md`
- Decisions for Luan: `production/team/decisions.md`

Stage: Concept (2026-11-17). Everything for this game (iOS, Android, docs, assets) lives in this
folder.

**This folder is its own studio project.** It links `.claude/` and `CLAUDE.md` from the repo
root and has its own `project.yaml`, so start Claude Code here (`tools/team/start-leader.sh`
does that) and the studio skills read and write this game's files.
Platforms: fully native, Apple first (iPadOS + macOS), then Android (K-03).
